# CashFlow AI

A bilingual financial analysis application built with Python and Streamlit.

CashFlow AI aims to help users organize and analyze financial transactions through a simple and interactive interface.

## Current Features

- Spanish and English interface
- CSV and Excel file upload
- Required column validation
- Income, expenses, and net cash flow calculations
- Expense analysis by category
- Interactive expense category chart
- Transaction type selector

## Technologies

- Python
- Streamlit
- Pandas
- Plotly
- OpenPyXL

## Data Format

The application expects the following columns:

- `Date`
- `Description`
- `Category`
- `Type`
- `Amount`

The `Type` column currently uses `Income` and `Expense`.

**In development**
